# The Watcher — Fabric 1.21.1

## Requirements
- Minecraft 1.21.1
- Fabric Loader
- Fabric API for 1.21.1
- Java 21 (JDK)

## Build
Open this folder in IntelliJ IDEA as a Gradle project, or run:
```bash
gradle build
```
The mod JAR will be created in `build/libs/`.

## Install
Copy the generated `the-watcher-1.0.0.jar` into your Minecraft instance's `mods` folder.
Install Fabric API in the same instance.
